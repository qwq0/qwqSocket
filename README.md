# QwQ Socket

一个有趣的长连接通信库(及协议)  
适用于 nodejs 和 web

## 为什么使用这个库?

-   ### 使用简单
    仅需配置需要的事件和类型即可使用  
    并能以最快的方式上手
    使用方法就像调用本地的异步函数一样简单
-   ### 维护简单
    仅需维护一份 "事件和类型表"  
    之后这些内容可以在服务端与客户端见共享
-   ### 提高接口安全性
    支持在任意一端检查传入的类型是否符合规范  
    服务端默认会自动检查客户端传入的类型是否正确  
    且支持更复杂的自动检查 如数值范围 字符串长度等
-   ### 良好的类型检查与编辑器提示
    完全兼容 jsdoc/typescript 的类型提示  
    支持对接口导出自定义独立 d.ts 文件

## 关键特性

-   ### 双向事件
    支持在服务器或客户端向对端发送事件  
    支持在任意一端监听事件  
-   ### 查询与返回
    支持在服务器或客户端向对端发起请求  
    并等待对端响应
-   ### 与各种序列化方式兼容
    协议并不指定序列化方法  
    用你喜欢的任何方式  
    JSON JSOBin 或你能想到的其他方式...
-   ### 与各种传输协议兼容
    协议并不指定传输协议  
    用你喜欢的任何方式 也可以任意加入加密或压缩  
    WebSocket WebRTC WebTransport 或你能想到的其他方式...
-   ### 事件名压缩
    QwQ socket 协议在内部将事件名转为简短形式  
    无需手动使用缩写事件名  
    放心的使用更长的事件名以提高代码和接口文档的可读性
